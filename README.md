## Overview
This is my NEA A level CS project. It is a factory/resource management game inspired by Factorio.
I made this project since I was curious on how I could code conveyor belts and item placing from inventory. I learnt alot from this project. I learnt different design patterns such as factory pattern, or observer pattern which created more possibilities in adding different, more complex features. 
This project is made purely in Java. Graphics is generated by Java swing. 

## Key Features
- Inventory item management
- Hotbar system
- Functional, reliable conveyor belt system.
- Saving/Loading from binary file.
- Crafting
- Menu and other UI interface.
- Large Tile World
- Chunk based rendering with Camera Culling

## How to play
- WASD keys to move around
- [I] to open/close Inventory.
- [F] to pickup nearby items from conveyor belts.
- [Q] & [E] to rotate placeable selected objects.
- Click at item in inventory to select, Press 1-8  to asign it to the hotbar while selected.
